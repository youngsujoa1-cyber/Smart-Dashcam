RoadEyeCam

차량용 블랙박스 앱 · 개발자 Topster

RoadEyeCam은 운전 중 필요한 순간을 놓치지 않도록 만든 차량용 블랙박스(대시캠) 앱입니다. 녹화 영상과 소리는 오직 이용자의 기기에만 저장되며, 외부 서버로 전송되지 않습니다.

주요 기능

HUD 속도 표시

GPS 속도를 녹화 화면에 표시해 주행 상황을 한눈에 확인할 수 있습니다.

반복 녹화

저장 공간에 맞춰 오래된 클립을 자동으로 정리하며 계속 녹화합니다.

충격 감지 잠금

충격이 감지된 순간의 클립을 잠가 자동 정리에서 보호합니다.

백그라운드 녹화

화면이 꺼지거나 다른 앱을 쓰는 동안에도 녹화가 이어집니다.

전·후면 카메라 전환

녹화 중에도 전면과 후면 카메라를 바꿔 사용할 수 있습니다.

5개 언어 지원

앱 화면과 안내 문구를 원하는 언어로 사용할 수 있습니다.
